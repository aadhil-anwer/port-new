Aadhil Anwar

Security engineer working on network and cloud infrastructure.

I work in network security at GoDaddy: infrastructure security, access control architecture, and cloud security on AWS. Day to day that means segmentation and ACL design, and making sure controls still hold as the environment changes.

Before this I spent time on the offensive side, reporting high-severity vulnerabilities in production APIs. Most traced back to ordinary causes: trust placed in the client, access checks in the wrong place. That experience informs how I approach defense.

I write here about networks, security, and what I'm learning along the way.
